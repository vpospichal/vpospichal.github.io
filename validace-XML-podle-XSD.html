Validace XML podle vzdáleného XSD schématu

Pokud XML dokument odkazuje na XSD schéma pomocí vzdáleného URL (např. http://example.com/schema.xsd), je z důvodů bezpečnosti, stability a rychlosti nejlepším postupem schéma nejprve stáhnout do dočasného adresáře na lokální disk a následně provést validaci lokálně.

Proč nestahovat přímo přes libxml2? Vyhnete se chybám při výpadku sítě, zbytečnému přetěžování vzdáleného serveru při každém požadavku a rizikům spojeným s externími entitami (XXE útoky).

1. Kompletní řešení v PHP

Skript využívá cURL pro bezpečné stažení schématu přes HTTP/HTTPS a ukládá jej do dočasného souboru pomocí sys_get_temp_dir().

<?php
// Aktivace interního zachytávání chyb pro libxml
libxml_use_internal_errors(true);

$xmlFile = 'data.xml';

$xml = new DOMDocument();
if (!$xml->load($xmlFile)) {
    echo "Chyba: XML soubor nelze načíst.
";
    exit(1);
}

// 1. Zjištění cesty k XSD schématu pomocí XPath
$xpath = new DOMXPath($xml);
$xpath->registerNamespace('xsi', 'http://www.w3.org/2001/XMLSchema-instance');

$xsdPath = $xpath->evaluate('string(/*/@xsi:noNamespaceSchemaLocation)');
if (empty($xsdPath)) {
    $schemaLocation = $xpath->evaluate('string(/*/@xsi:schemaLocation)');
    if (!empty($schemaLocation)) {
        $parts = preg_split('/\s+/', trim($schemaLocation));
        $xsdPath = end($parts);
    }
}

if (empty($xsdPath)) {
    echo "Chyba: XML dokument neobsahuje odkaz na XSD schéma.
";
    exit(1);
}

// 2. Kontrola, zda se jedná o vzdálené URL a jeho stažení
if (filter_var($xsdPath, FILTER_VALIDATE_URL)) {
    echo "Detekováno vzdálené URL schématu: $xsdPath
";
    
    $localXsdPath = sys_get_temp_dir() . '/downloaded_schema_' . md5($xsdPath) . '.xsd';
    
    // Stažení schématu pomocí cURL
    $ch = curl_init($xsdPath);
    $fp = fopen($localXsdPath, 'wb');
    curl_setopt($ch, CURLOPT_FILE, $fp);
    curl_setopt($ch, CURLOPT_HEADER, 0);
    curl_setopt($ch, CURLOPT_FOLLOWLOCATION, true);
    curl_setopt($ch, CURLOPT_TIMEOUT, 10);
    
    if (curl_exec($ch) === false || curl_getinfo($ch, CURLINFO_HTTP_CODE) !== 200) {
        echo "Chyba: Nepodařilo se stáhnout XSD schéma ze vzdáleného serveru.
";
        fclose($fp);
        curl_close($ch);
        exit(1);
    }
    
    fclose($fp);
    curl_close($ch);
    $validationPath = $localXsdPath;
} else {
    // Lokální soubor - sestavení absolutní cesty
    $xmlDir = dirname(realpath($xmlFile));
    $validationPath = $xmlDir . '/' . $xsdPath;
}

// 3. Spuštění validace
if ($xml->schemaValidate($validationPath)) {
    echo "ÚSPĚCH: XML soubor je VALIDNÍ.
";
} else {
    echo "CHYBA: XML soubor je NEVALIDNÍ. Nalezené chyby:
";
    $errors = libxml_get_errors();
    foreach ($errors as $error) {
        echo sprintf("- Řádek %d: %s", $error->line, trim($error->message)) . "
";
    }
    libxml_clear_errors();
}

// Vyčištění staženého souboru (volitelné)
if (isset($localXsdPath) && file_exists($localXsdPath)) {
    unlink($localXsdPath);
}

2. Kompletní řešení v Bashi

Bash skript využívá nástroje curl nebo wget ke stažení schématu do složky /tmp a následně použije xmllint.

#!/bin/bash

XML_FILE="data.xml"
TMP_XSD="/tmp/downloaded_schema_$$.xsd"

# 1. Zjištění cesty k XSD z XML pomocí xmllint
XSD_PATH=$(xmllint --xpath "string(/*/@*[local-name()='noNamespaceSchemaLocation'])" "$XML_FILE" 2>/dev/null)

if [ -z "$XSD_PATH" ]; then
    XSD_PATH=$(xmllint --xpath "string(/*/@*[local-name()='schemaLocation'])" "$XML_FILE" 2>/dev/null | awk '{print $2}')
fi

if [ -z "$XSD_PATH" ]; then
    echo "Chyba: V XML nebylo nalezeno žádné XSD schéma."
    exit 1
fi

# 2. Rozhodnutí, zda stahovat z internetu nebo číst lokálně
if [[ "$XSD_PATH" =~ ^https?:// ]]; then
    echo "Stahuji vzdálené schéma: $XSD_PATH ..."
    
    # Stažení pomocí curl
    curl -s -f -L "$XSD_PATH" -o "$TMP_XSD"
    
    if [ $? -ne 0 ]; then
        echo "Chyba: Nepodařilo se stáhnout vzdálené XSD schéma."
        exit 1
    fi
    VALIDATION_SCHEMA="$TMP_XSD"
else
    VALIDATION_SCHEMA="$XSD_PATH"
fi

# 3. Samotná validace
echo "Spouštím validaci..."
OUTPUT=$(xmllint --schema "$VALIDATION_SCHEMA" "$XML_FILE" --noout 2>&1)
STATUS=$?

# Úklid dočasného souboru
[ -f "$TMP_XSD" ] && rm "$TMP_XSD"

# Vyhodnocení
if [ $STATUS -eq 0 ]; then
    echo "ÚSPĚCH: XML je validní."
    exit 0
else
    echo "CHYBA: Validace selhala!"
    echo "$OUTPUT"
    exit 1
fi
Upozornění k síťovému provozu: Pokud skript zpracovává velké množství XML souborů se stejným vzdáleným URL, doporučuje se implementovat lokální mezipaměť (cache), aby se stejný soubor nestahoval opakovaně při každém spuštění.
